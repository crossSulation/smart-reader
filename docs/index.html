Smart Reader

Read smarter. Learn faster.

Smart Reader is an AI-powered document reader for PDF, EPUB, and Markdown. Built with Tauri 2.0 — runs on desktop (Windows/macOS/Linux) and mobile (Android).

Get started View on GitHub

Key Features

  • Multi-format Reader

    Native PDF viewer with page navigation and thumbnails. EPUB reader with contents sidebar and reading themes. Markdown viewer with heading-based TOC, LaTeX math, Mermaid diagrams, and SMILES chemical structures. Mobile PDF viewer with server-side page rendering and rectangle-based annotations.

  • AI Agent Chat

    Unified chat interface powered by a LangChain tool-calling agent. Ask questions, get explanations, generate quizzes, create flashcards, search the web, and save notes — all in one conversation. Streaming token output with real-time tool step visualization.

  • Knowledge Graph

    Automatically extract key concepts, terms, and entities from ingested documents. Visualize relationships as an interactive force-directed graph. Click nodes to view details and linked pages. Supports cross-document relationship inference via embedding similarity + LLM. Responsive mobile view with list/detail navigation.

  • Spaced Repetition Review

    SM-2 algorithm with fuzz factor for optimized flashcard scheduling. Review due cards with "Again / Hard / Good / Easy" ratings. Notes tab for browsing saved annotations. Filter by book or tag. Flashcards auto-generated by the AI agent and persisted for review.

  • Learning Workflow

    Select text → Explain, Translate (Chinese / English), or Save as Note. Link notes to knowledge points. Notes list with inline editing, tags, and page jump. Markdown export for notes and CSV export for flashcards.

  • Text-to-Speech (TTS)

    Built-in read-aloud with system speech synthesis. Sentence-by-sentence playback with play/pause/skip controls. Adjustable speed (0.5x–2x) and voice selection. Supports Chinese voices. Works offline on both desktop and mobile.

  • Book Sharing & Collaboration

    Share books with other users by username. Searchable user picker. Shared books appear in "Shared with me" section with one-click read access. View and add comments on shared books. See each other's notes.

  • Reading Experience

    Dark mode with system preference detection. PDF reading themes (default / eye-care warm / e-ink dark). Keyboard shortcuts for navigation. Desktop AIPanel with drag-to-resize. Mobile floating AI panel with slide-out overlay. Swipe and edge-tap page navigation.

  • Hybrid AI Architecture

    Route AI tasks to local models (Ollama) or cloud providers (OpenAI, Anthropic, DeepSeek) based on capability and privacy mode. Local embedding with sentence-transformers. Reranking pipeline for retrieval quality. Confidence-gated fallback from local to cloud.

  • Token Billing & Credits

    Track cloud AI token consumption per capability. Credit point system with monthly free allowance. Purchase credit packs. Real-time balance display with low-credit warnings. All local/Ollama calls are free.

  • Desktop & Mobile App

    Built with Tauri 2.0 for Windows, macOS, Linux, and Android. Mobile bottom tab navigation (Bookshelf / Review / Knowledge / Profile). Native title bar with window controls on desktop. Edge-to-edge display with safe area padding on mobile. Offline file caching via IndexedDB. SQLite for local data storage. Full functionality without a browser.

Quick Start

1. Clone & Install

git clone https://github.com/crossSulation/smart-reader.git
cd smart-reader/frontend && npm install

2. Backend Setup

cd smart-reader/backend
uv venv --python 3.12
uv pip install -r requirements.txt PyMuPDF

3. Configure Environment

cp .env.dev .env
# Edit .env — set LLM_PROVIDER, LLM_API_KEY, etc.

4. Run

# Web mode
cd backend && .venv\Scripts\python run_dev.py
cd frontend && npm run dev

# Desktop mode
start_desktop.bat

# Android dev mode
cd frontend && npm run tauri android dev

Architecture

Frontend

  • React 18 + TypeScript
  • Vite build system
  • Tailwind CSS + MUI
  • Tauri 2.0 desktop + mobile shell
  • react-pdf / server-rendered PDF
  • epubjs, react-markdown
  • vis-network graph visualization

Backend

  • FastAPI + SQLAlchemy
  • SQLite database (sync + async)
  • LangChain agent (7+ tools)
  • sentence-transformers embeddings
  • PyMuPDF page rendering
  • OpenAI / Ollama / DeepSeek LLM
  • JWT authentication

AI Pipeline

  • Hybrid retrieval (BM25 + vector)
  • Cross-encoder reranking
  • Tool-calling agent (search / qa / flashcard / summary / note / web-reference / cross-book-search)
  • Knowledge extraction + batch relation inference
  • Token counting + credit billing
  • SM-2 spaced repetition + FSRS training
